# Project Rules: Language and Documentation Standards

## Primary Language: English
1. **Repository-Wide English Rule**:
   - All documentation, specifications, architectural guides, roadmaps, and README files in this repository MUST be written in English.
   - All source code, including identifiers, variable names, functions, classes, database schemas, API routes, and code comments, MUST be written in English.
   - Commit messages and pull request descriptions MUST be written in English.
   - User-facing error messages, system logs, and default data seeds MUST be defined in English (with i18n support reserved for frontend localization where applicable).

2. **File & Specification Integrity**:
   - Keep technical terms consistent across backend (Go), frontend (Flutter), and database specifications (PostgreSQL).
