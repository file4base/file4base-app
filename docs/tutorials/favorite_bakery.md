# Retired Tutorial Path (`favorite_bakery.md`)

This path previously held an introductory tutorial whose business scenario
(*Favorite Bakery* annual-fee discount program and example company names)
overlapped the sample setting used in Claris's historical FileMaker Pro 12
tutorial documentation.

As part of the preventive intellectual-property and documentation remediation
tracked in [Issue #41](https://github.com/file4base/file4base-app/issues/41) and
[Issue #44](https://github.com/file4base/file4base-app/issues/44), that scenario
was retired and replaced by an independently authored, domain-distinct tutorial
created specifically for File4Base:

- **[File4Base Tutorial — Boreal Seed & Herbarium Archive (`seed_archive.md`)](seed_archive.md)**

See [`docs/PROVENANCE.md`](../PROVENANCE.md) and [`docs/LEGAL.md`](../LEGAL.md)
for the source review and remediation record.
